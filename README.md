### Development

If python is installed, the app can be served via `python3 -m http.server 8080` and viewed at http://localhost:8080.
Any equivalent HTTP file server can be used.

#### Accessibility

Check overall accessibility using [WAVE](https://wave.webaim.org/report#/https://jsha-unt.github.io/csce-3444-group-2/).

Check contrast with the [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/).

### Testing

Run tests via `node --test`.
